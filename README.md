# CRONET Accounting — Instaladores

Este repositorio público contiene únicamente instaladores y avisos firmados de actualización. No incluye código fuente ni datos empresariales.

## Descargar

[Última versión publicada](https://github.com/cronetegm-cpu/CRONET-Contabilidad-Releases/releases/latest).

Si utilizas 0.5.6 o una versión anterior, respalda tu empresa, cierra CRONET e instala **0.5.7 manualmente una vez** para adoptar el canal de firma recuperado. Abre después tu archivo de empresa habitual; no necesitas reiniciar los datos de demostración.

Las versiones posteriores se comprueban desde la app. Cada publicación incorpora un instalador y update.json con firma Ed25519, tamaño y SHA256 verificados. La clave privada no se distribuye. Esta firma del aviso no equivale a un certificado Authenticode de Windows.

El programa sigue siendo un prototipo de prueba.
